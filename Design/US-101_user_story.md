# US-101 เลือกเมนูอาหารและดูสรุปรายการสั่ง (Office Food Ordering)
Version: req v1.1 (2026-11-18, clarifications BA-C1, BA-C2) | Owner: 201 BA | Status: Closed (2026-11-18, web v1.0.1)

## User Story
ในฐานะ พนักงานในออฟฟิศ ฉันต้องการ ดูเมนูอาหารพร้อมราคา เลือกอาหารที่ต้องการ และเห็นสรุปรายการที่สั่ง เพื่อ ตรวจสอบได้ว่าสั่งอะไร จำนวนเท่าไร และราคารวมเท่าไร

## ขอบเขต (ทำเท่านี้เท่านั้น)
- แสดงเมนูอาหาร (ชื่อ, ราคา บาท) ให้เลือก
- เลือกอาหารเข้า "สรุปรายการที่สั่ง"
- หน้าตาใช้งานง่าย มีสีสันสวยงาม รองรับมือถือและเดสก์ท็อป
- นอกขอบเขต: ล็อกอิน, ยืนยัน/ส่งคำสั่งซื้อ, ชำระเงิน, บันทึกคำสั่งซื้อลงฐานข้อมูล, ลด/ลบรายการ, จัดการเมนู

## Acceptance Criteria
- AC1 แสดงเมนูทุกรายการที่มีในข้อมูล (สถานะ available) พร้อมชื่อและราคาเป็นบาท ตรงกับข้อมูลต้นฉบับ
- AC2 กดเลือกเมนูครั้งแรก รายการนั้นปรากฏในสรุปด้วยจำนวน 1
- AC3 กดเลือกเมนูเดิมซ้ำ จำนวนของบรรทัดเดิมเพิ่มขึ้นทีละ 1 ทุกครั้ง (ไม่สร้างบรรทัดซ้ำ) เช่น กด 3 ครั้ง = จำนวน 3
- AC4 เลือกหลายเมนู สรุปแสดงครบทุกเมนูที่เลือก จำนวนตรงกับจำนวนครั้งที่กดของแต่ละเมนู ไม่มีรายการหายหรือเกิน
- AC5 แต่ละบรรทัดแสดง ราคาต่อหน่วย x จำนวน = ราคารวมบรรทัด และมีจำนวนชิ้นรวมทั้งหมดและราคารวมทั้งหมดที่คำนวณถูกต้อง
- AC6 ยังไม่เลือกอะไร สรุปแสดงข้อความว่ายังไม่มีรายการ ยอดรวม 0 บาท
- AC7 ใช้งานได้บน URL Production ของ Vercel ทั้งจอมือถือ (≥360px) และเดสก์ท็อป ไม่มี error ใน console

## ข้อมูลที่ใช้
- ตาราง Supabase `menu_items`: id (int, PK), name (text), price (numeric, บาท, >0), category (text, optional), image_url (text, optional), is_available (bool, default true), sort_order (int)
- Mock data: Design/data/menu_items.csv และ .json (203 จัดทำ/ขยายเพื่อทดสอบ)
- รายการที่เลือกเก็บใน state ของเบราว์เซอร์เท่านั้น (ไม่บันทึก DB)

## กติกา
- ราคารวมบรรทัด = price x qty; ยอดรวม = ผลรวมทุกบรรทัด; แสดงเป็นบาท
- 1 เมนู = 1 บรรทัดในสรุป

## Dependencies
- ไม่มี (Story แรก) ต้องมีโปรเจกต์ Vercel และ Supabase table `menu_items`

## Clarifications (req v1.1, ตัดสินโดย 201 BA จากข้อมูลที่มี)
- BA-C1 รูปแบบราคา: แสดงทศนิยม 2 ตำแหน่งเสมอ และมีคอมมาคั่นหลักพัน ตามด้วย "บาท" หรือ "฿" (เช่น 45.50, 1,250.00) ใช้กับราคาต่อหน่วย ราคารวมบรรทัด และยอดรวม
- BA-C2 รีเฟรชหน้า: สรุปรายการล้างกลับเป็นว่าง (0 บาท) เพราะรายการเก็บใน state ของเบราว์เซอร์เท่านั้น การคงรายการหลังรีเฟรชอยู่นอกขอบเขต US-101
- เมนูที่ is_available = false ต้องไม่แสดง
